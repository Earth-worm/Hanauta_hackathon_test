# Hanalog（ハナログ）

グループで短い動画を共有するスマホアプリです。
**Flutter** と **Supabase** で動いています。

---

## 全体の流れ

```
【事前に自分で準備】 VS Code・Chrome・Git・GitHub アカウント
        ↓
【当日みんなで】    Flutter → clone → .env → 起動！
        ↓
【動いたら】        必須課題 → 自由課題に挑戦
        ↓
【好きなタイミングで】Claude Code 設定 ／ スマホ配布設定
```

> 💡 開発は **Chrome（ブラウザ）** で行います。Windows でも Mac でも同じです。
> スマホでの確認は `main` に push すると**自動でブラウザに反映される**仕組みです（後述）。

## 📱 スマホでの確認について

`main` に push すると **GitHub Actions** が自動でビルドして GitHub Pages に公開し、
数分後にはスマホのブラウザで最新版が見られます。インストール操作は不要です（PWA）。

設定は運営側で済ませてあるので、**参加者は何も設定する必要はありません。**
配られた URL をブラウザで開くだけです。詳しい流れは [開発の流れ](docs/05_開発の流れ.md) を参照してください。

## 困ったときは

| こんな症状 | こうする |
|---|---|
| `flutter` コマンドが見つからない | インストール or PATH 設定を見直す（[環境構築](docs/02_環境構築.md) ステップ1） |
| `git clone` でアクセスできない | GitHub の招待を承認したか確認（[環境構築](docs/02_環境構築.md) ステップ2） |
| 起動したらエラー画面が出る | `.env` の URL・Key が正しいか確認（[環境構築](docs/02_環境構築.md) ステップ3） |
| ログインできない | 運営に連絡 |
| `claude` コマンドが見つからない | Node.js と Claude Code のインストール確認（[環境構築](docs/02_環境構築.md) ステップ4） |
| push したのにスマホに届かない | 2〜3分待つ / ブラウザのキャッシュを確認（タブを閉じて開き直す） |
