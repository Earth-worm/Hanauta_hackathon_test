# 自由課題

[必須課題](03_必須課題.md) が終わったチームは、ここから好きな課題を選んで挑戦しましょう。
初級・中級・上級の3レベルに分かれています。

---

## 課題設計の考え方

今回のハッカソンでは、基本的にこちらで用意したSupabase環境を使って開発します。

そのため、初級〜中級の課題では **新しいテーブルを追加しなくても実装できるもの** を中心にします。

Flutter側の見た目変更、既存データの表示、既存カラムへの更新などを通して、まずはアプリ開発に慣れてもらうことが目的です。

一方で、より本格的にバックエンドやDB設計にも触れたい人向けに、上級として **自分たちのSupabaseを作るコース** を用意します。

上級コースでは、likesテーブル、commentsテーブルなど**必要なテーブルを自分たちで設計・作成**した上で、それらを使う課題に挑戦してもらいます。

## レベル分けの意図

### 初級

Flutterだけで完結する課題。

DBや認証に触れず、まずは画面変更・アニメーション・状態管理に慣れる。

### 中級

こちらで用意したSupabaseを使う課題。

新しいテーブルは作らず、既存のデータを読む・更新する・集計する体験をする。

### 上級

自分たちでSupabase環境を作る課題。

必要なテーブルを自分でSQLを書いて用意し、DB設計・リレーション・リアルタイム更新まで触れる。

---

## 上級コースの流れ

1. 自分たちのSupabaseプロジェクトを作成する
2. [supabase/schema.sql](../supabase/schema.sql) を SQL Editor で実行する（中級までと同じテーブルが再現される）
3. likes / comments / reactions などに必要なテーブルを自分で設計し、SQLを書いて追加する
4. アプリ側のSupabase URL / anon keyを差し替える（手順は下記）
5. likes / comments / reactions などの課題に取り組む

上級コースは、FlutterだけでなくバックエンドやDBにも触れたいチーム向けの発展課題として扱う。

---

## 上級コース：自分のSupabaseセットアップ手順

### 1. プロジェクトを作成する

[supabase.com/dashboard](https://supabase.com/dashboard) で新しいプロジェクトを作成する。

### 2. テーブルを作る

1. [supabase/schema.sql](../supabase/schema.sql) を SQL Editor で実行する（users / groups / group_members / posts / post_shares など中級までの基本テーブルが作られる）
2. likes / comments / reactions など、挑戦する課題に必要なテーブルを自分でSQLを書いて作成する

### 3. URL / anon keyを確認する

1. ダッシュボード左メニューの **Settings**（歯車アイコン）→ **Data API** を開く
2. **Project URL**（`https://xxxxx.supabase.co`）と、**Project API keys** の `anon` `public` キーをコピーする
3. プロジェクト直下の `.env` を以下のように書き換える

   ```
   SUPABASE_URL=https://xxxxx.supabase.co
   SUPABASE_ANON_KEY=xxxxx
   ```

### 4. GitHub Secrets も更新する

`.env` はローカル確認用です。**スマホのブラウザで見ている公開版（GitHub Pages）は
GitHub の Secrets を見てビルドされる**ので、そちらも同じ値に更新しないと
公開版だけ古いSupabaseを向いたままになります。

1. リポジトリの **Settings → Secrets and variables → Actions** を開く
2. `SUPABASE_URL` と `SUPABASE_ANON_KEY` をそれぞれ **「Update」** して、上と同じ値に書き換える
3. 何か1行変更して push すると再ビルドされ、数分後に公開版にも反映される

### 5. 「Confirm email」をOFFにする（重要）

このアプリは「新規登録＝即セッション開始（メール確認なし）」という前提で作られている（[login_screen.dart](../lib/features/auth/login_screen.dart)参照）。

新しく作ったSupabaseプロジェクトは**デフォルトでメール確認がON**になっているため、そのままだと新規登録時に

> メールアドレスの形式が正しくありません

というエラーが出て登録できない（実際はメール確認まわりのエラーで、入力したメールアドレス自体は正しい）。

必ず以下を設定すること。

1. ダッシュボードの **Authentication** → **Sign In / Providers**（または **Settings**）を開く
2. **Email** プロバイダーの設定にある **「Confirm email」をOFF**にする

### 6. アプリを再起動する

`.env` を書き換えたら、アプリを再起動（ホットリロードではなく再起動）して反映させる。
